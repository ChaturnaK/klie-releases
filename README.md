# Klie releases

Installers for **Klie**, the desktop app that turns long videos into short clips with AI and lets
you edit them in a layered editor.

**Download:** open the [latest release](https://github.com/ChaturnaK/klie-releases/releases/latest)
and pick:

- **Windows:** `Klie-Setup-<version>.exe`
- **Mac (Apple silicon, M1 and later):** `Klie-<version>-mac-arm64.dmg`

Klie updates itself from here, so you only download it once.

Klie Free adds the Klie watermark to videos. Klie Pro has no watermark: $20 for one year, on up to
2 computers. Paste your licence key in Klie → Settings → Licence.

This repository holds only the installers; it has no code.
